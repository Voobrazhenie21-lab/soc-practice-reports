# Практические работы по кибербезопасности

Серия практических работ по защите инфраструктуры и наступательной безопасности (Red/Blue Team), выполненных на учебном стенде домена **ACME (acme.skb)** в облаке VK Cloud Solutions. От разведки сети и построения системы мониторинга до пентеста и атак на Active Directory.

## О стенде

- Облако: **VK Cloud Solutions** (VK CS), доступ по VPN (WireGuard)
- Домен: **acme.skb** (Active Directory, контроллер домена на Windows Server 2019)
- Сегменты сети: DMZ (10.0.10.0/24), корпоративный (10.0.20.0/24), офисный (10.0.30.0/24)
- Атакующая машина: **Kali Linux**, защищаемая инфраструктура: Windows/Linux хосты, Wazuh, ELK, TheHive и др.

## Ключевые навыки

- **Blue Team:** SIEM/мониторинг (Wazuh), контроль целостности файлов (FIM/whodata), аудит ОС Windows/Linux, реагирование на инциденты (TheHive, плейбуки), Fail2ban
- **Red Team:** разведка и сканирование (Nmap), взлом и перебор паролей (Hashcat, John the Ripper), эксплуатация учётных данных, атаки на Kerberos/NTLM, анализ AD-графов (BloodHound)
- **Инженерия:** планирование внедрения СЗИ, RACI, оценка угроз по открытым источникам

## Дисклеймер

Все работы выполнены в **изолированной учебной инфраструктуре** в рамках курса обучения. Использование описанных техник против систем без разрешения владельца незаконно (ст. 361 УК РБ / ст. 272–274 УК РФ).
